## Sobre a entrega

Este repositório reúne a documentação da disciplina **Software Engineering and Business Model (SEBM)**, desenvolvida pela **Equipe Politech** para a Global Solution 2026/2 da FIAP, com o tema **CitizenTech**.

O **Polieus** é uma proposta de plataforma de tecnologia cívica para registro, acompanhamento e análise de problemas urbanos. Seu recorte inicial é a cidade de **São Paulo (capital)**, com foco em **acessibilidade** e **pavimentação**. A solução busca aproximar cidadãos e gestores públicos, dando mais transparência às solicitações e apoiando decisões baseadas em dados.

Nesta disciplina, o grupo documentou tanto os aspectos de **engenharia de software** quanto a **proposta de viabilidade e modelo de negócios** da solução.

## Modelo de negócios — resumo do estudo

O documento apresenta uma proposta **B2G (Business-to-Government)**, na qual prefeituras seriam contratantes, enquanto cidadãos utilizariam as funcionalidades públicas gratuitamente. As estimativas acadêmicas apresentadas incluem:

| Indicador do estudo | Valor apresentado |
| --- | ---: |
| SaaS anual projetado | **R$ 81.448,20** |
| Implantação estimada | **R$ 2.265,47** |
| ROI calculado no cenário simulado | **26,14%** |
| Meta proposta de disponibilidade (SLA) | **99,5%** |

> **Importante:** os valores são projeções e simulações acadêmicas descritas na documentação. Não representam contratos efetivos, desempenho em produção ou garantia de retorno financeiro.
